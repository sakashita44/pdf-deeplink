# リンクの形式

リンクは、対象の PDF、版、ページ、範囲を URL のパスとクエリで表す。

```text
/view?src=zotero:ABCD1234&sha256=<16 桁>&page=12&rects=72,140,240,18;72,158,180,18&label=iv&q=<目印>
```

## パラメータ

| 名前     | 必須 | 内容                                                                                             |
| -------- | ---- | ------------------------------------------------------------------------------------------------ |
| `v`      | 任意 | リンク形式の版。省略した場合は `1` として解釈される                                              |
| `src`    | 必須 | 取得元と ID。`zotero:` に続けて、添付ファイルのアイテムキー（英大文字と数字の 8 文字）を指定する |
| `sha256` | 必須 | リンク発行時点の PDF の SHA-256。英小文字の 16 進数 16〜64 桁（発行時は先頭 16 桁）              |
| `page`   | 必須 | PDF 上のページ番号（1 始まり）                                                                   |
| `rects`  | 必須 | 範囲の矩形 `x,y,幅,高さ` を `;` で区切った配列。1〜64 個                                         |
| `label`  | 任意 | 誌面のページラベル。64 文字以内                                                                  |
| `q`      | 任意 | 利用者が該当箇所を探すための目印（引用、図表番号、メモ）。200 文字以内                           |

文字数は Unicode のコードポイントで数える。`:`、`,`、`;` はパーセントエンコードせずに記述してよい。

1 つのリンクが指す範囲は 1 ページ内に限る。

## 座標

`rects` の座標は、PDF のページに設定された回転（`/Rotate`）と表示領域（CropBox）を適用した表示上のページの左上を原点とし、右方向と下方向を正とする。単位は PDF ポイント（1/72 インチ）で、値は小数第 1 位に丸める。

ページ画像を対象とする処理（画像上での範囲の特定や範囲の切り出し）で表示上の座標をそのまま利用できるよう、表示上のページを基準とする。PDF のユーザー空間との変換式は PDF.js の `PageViewport` と同じである。

## 版の照合

`sha256` には、リンク発行時点の PDF のバイト列から計算した SHA-256 の先頭 16 桁を記録する。解釈では 16〜64 桁を受け付け、リンクの `sha256` が対象の PDF の SHA-256 の先頭と一致すれば同じ版とみなす。

版が一致しない場合は、PDF が更新されて `rects` の座標がずれている可能性がある。その場合、`page`、`label`、`q` が該当箇所を確認する手がかりとなる。

## テストベクタ

リンクの解釈と座標変換の期待値は、言語に依存しない JSON 形式で [`spec/`](../spec/) に定義されている。別の言語で実装する場合も、同じテストベクタで検証できる。

- `spec/link-vectors.json`: クエリの解釈、生成、版の照合
- `spec/geometry-vectors.json`: 回転ごとの座標変換と、行の矩形の結合
