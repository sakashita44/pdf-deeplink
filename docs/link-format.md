# リンクの形式

リンクは、PDF の版、ページ、範囲を、ビューアの URL のパスとクエリで表す。ホスト名は形式に含めない。ビューアがコピーするリンクには、貼り付けた先でそのまま開けるよう、利用中の環境のオリジンが付与される。配置先のオリジンが変わった場合は、発行済みのリンクのオリジンを書き換えて用いる。

リンクはサーバに保存しない。リンクの内容だけで、移動先と強調する範囲が定まる。

```text
/view?src=zotero:ABCD1234&sha256=<64 桁>&page=12&rects=72,140,240,18;72,158,180,18&label=iv&q=<目印>
```

## パラメータ

| 名前     | 必須 | 内容                                                                                             |
| -------- | ---- | ------------------------------------------------------------------------------------------------ |
| `v`      | 任意 | リンク形式の版。省略した場合は `1` として解釈される                                              |
| `src`    | 必須 | 取得元と ID。`zotero:` に続けて、添付ファイルのアイテムキー（英大文字と数字の 8 文字）を指定する |
| `sha256` | 必須 | リンク発行時点の PDF の SHA-256。英小文字の 16 進数 64 桁                                        |
| `page`   | 必須 | PDF 上のページ番号（1 始まり）                                                                   |
| `rects`  | 必須 | 範囲の矩形 `x,y,幅,高さ` を `;` で区切った配列。1〜64 個                                         |
| `label`  | 任意 | 誌面のページラベル。64 文字以内                                                                  |
| `q`      | 任意 | 人が該当箇所を探すための目印（引用、図表番号、メモ）。200 文字以内                               |

文字数は Unicode のコードポイントで数える。`:`、`,`、`;` は符号化せずに書いてよい。

1 つのリンクが指す範囲は 1 ページ内に限る。ビューアでページをまたぐ範囲や、矩形の数が上限を超える範囲を選択した場合、リンクは発行されない。

## 座標

`rects` の座標は、PDF のページに設定された回転（`/Rotate`）と表示領域（CropBox）を適用した表示上のページについて、左上を原点とし、右方向と下方向を正とする。単位は PDF ポイント（1/72 インチ）で、値は小数第 1 位に丸める。利用者がビューアで加えた回転や拡大率は反映されない。

ページ画像を対象とする処理（画像上での範囲の特定や、範囲の画像の切り出し）が、表示上の座標をそのまま利用できるよう、表示上のページを基準とする。PDF のユーザー空間との変換式は PDF.js の `PageViewport` と同じである。

## 版の照合

ビューアは受け取った PDF のバイト列から SHA-256 を計算する。リンクの `sha256` と一致しない場合は範囲を強調表示せず、`page`、`label`、`q` を表示する。利用者は、そのページへの移動と、`q` による本文の検索を選べる。古い範囲を別の版の PDF に適用することはない。

## テストベクタ

リンクの解釈と座標の変換の期待値は、言語に依存しない JSON で [`spec/`](../spec/) に定義されている。別の言語で実装する場合も、同じテストベクタで検証できる。

- `spec/link-vectors.json`: クエリの解釈と生成
- `spec/geometry-vectors.json`: 回転ごとの座標変換と、行の矩形の結合
